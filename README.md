KrashCode — терминальный ИИ-агент для работы с кодом. Читает и изменяет файлы, ищет по проекту,
запускает команды и стримит ответы в интерактивном TUI.

Построен на TypeScript, React/Ink и Vercel AI SDK. Поддерживает OpenAI, Anthropic, Google и
OpenAI-совместимые провайдеры (OpenRouter, Ollama и т.д.).

## Возможности

- потоковые ответы от ИИ в реальном времени, с выводом reasoning
- чтение, создание и точечное редактирование файлов (с защитой от выхода за пределы проекта)
- поиск по именам и содержимому файлов (glob/grep)
- запуск shell-команд с таймаутом и обрезкой вывода
- режимы `normal` / `accept` / `plan` и подтверждение вызовов инструментов
- долговременная память проекта (`/memory`) — заметки живут между сессиями
- сжатие контекста (`/compact`), учёт токенов и оценка стоимости (`/usage`)
- переключение моделей и провайдеров (OpenAI, Anthropic, Google, OpenRouter, локальные)
- сохранение и восстановление сессий (`-c`, `-r`, `/sessions`)
- автодетект проверок проекта (lint/typecheck/test) после правок
- slash-команды с автодополнением и стильный минималистичный TUI

## Требования

- Node.js 22+
- npm

## Установка

```sh
git clone https://github.com/your-username/KrashCode.git
cd KrashCode
npm install
npm run build
npm link
```

## Настройка

```sh
# OpenAI
krashcode setup openai --model gpt-4o

# Anthropic
krashcode setup anthropic --model claude-sonnet-4-20250514

# Google
krashcode setup google --model gemini-2.5-flash

# OpenRouter
krashcode setup openrouter --model openai/gpt-4o --key-env OPENROUTER_API_KEY

# Локальный сервер (Ollama)
krashcode setup custom --model llama3 --base-url http://localhost:11434/v1
```

При `setup` без `--key-env` ключ спрашивается скрытым вводом и сохраняется в `~/.krashcode/auth.json`
(права `0600`). Иначе берётся из переменной окружения (`OPENAI_API_KEY`, `ANTHROPIC_API_KEY` и т.д.)
или из указанной в `--key-env`. Сменить ключ отдельно: `krashcode key <provider>`.

## Запуск

```sh
krashcode              # запустить TUI
krashcode -c           # продолжить последнюю сессию в этом каталоге
krashcode -r <id>      # возобновить сессию по id
krashcode --model <m>  # запуститься с выбранной моделью
krashcode config       # показать конфиг
krashcode sessions     # показать сессии
```

## Команды внутри TUI

| Команда | Действие |
|---------|----------|
| `/model [name]` | Сменить модель |
| `/mode [normal\|accept\|plan]` | Сменить режим (или `Shift+Tab` — цикл) |
| `/sessions` | Возобновить сохранённую сессию |
| `/compact` | Сжать старый контекст в резюме |
| `/memory [set <текст>\|clear]` | Заметки проекта между сессиями |
| `/bypass` | Вкл/выкл подтверждения вызовов |
| `/usage` | Токены и оценка стоимости |
| `/config` | Показать конфиг |
| `/clear` | Новая сессия |
| `/help` · `/exit` | Помощь / выход |
| `Esc` | Прервать запрос · очистить ввод · выйти (если пусто) |
| `Ctrl+C` | Выйти с сохранением сессии |

## Режимы

- `normal` — файловые правки и команды спрашивают подтверждение
- `accept` — правки `write`/`edit` применяются автоматически (bash всё равно спрашивает)
- `plan` — только чтение: изменяющие инструменты заблокированы, агент возвращает план

## Встроенные инструменты

| Инструмент | Описание |
|------------|----------|
| `read` | Чтение файла с нумерацией строк |
| `write` | Создание/перезапись файла |
| `edit` | Точечная замена фрагмента в файле |
| `bash` | Запуск shell-команды (с `background: true` — фоново, без ожидания) |
| `bash_output` | Чтение вывода фоновых команд, их список и остановка (`kill`) |
| `glob` | Поиск файлов по паттерну |
| `grep` | Поиск по содержимому файлов (regex) |
| `memory` | Чтение/обновление долговременных заметок проекта |

Долгие команды (dev-сервер, watcher, сборка) запускаются с `background: true` и не
блокируют агента: он читает их вывод через `bash_output`, а при выходе фоновые процессы
гасятся автоматически.
